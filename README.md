# ⚡ 1HP // SYNAPSE FLATLINE
### // ONE HIT. INSTANT KILL. BRUTAL MULTIPLAYER DUELS. //

1HP is a high-speed, premium neon cyberpunk multiplayer duel arena built with Node.js authoritive physics, Socket.IO real-time synchronization, Phaser 3 client rendering, and custom procedurally synthesized audio FX.

## 🚀 Features
* **4-Player Battle Royale Matchmaking**: Support for 1 to 4 players symmetrical spawn gates.
* **Resilient Authoritive Solid Physics**: Pillar obstacles and circular storm boundary walls act as solid blockades.
* **Lobby & In-Game Secure Chats**: Retractable HUD chat feeds color-coded by chassis with custom procedural audio chirps.
* **TAB Leaderboard Overlays**: Hold Tab key to inspect dynamic player cards, win gems, and alive/deceased state flags.
* **Auto-Fill Com-Links**: Send invite links (`/?join=XXXX`) to friends to auto-fill access codes and connect instantly.
